## What's new

- **The boot partition stays read-only.** The kernel and firmware are no longer exposed to writes while the Pi runs, so the car cutting the power is far less likely to leave a Pi that won't start. Glovebox opens it for a moment only to save its own setup files. Pis updated from the web are switched over on their first start.
- **Updates install the system packages they need**, before switching to the new version. If that fails, for example because the Pi is offline, the old version keeps running. Skipping versions is fine.
- **Safer encryption setup.** Before erasing anything, Glovebox now checks that it can write the recovery files and that the card has room for them.

## Fixes

- Recovery files and settings written to the boot partition could be left half-written by a power cut.
- An interrupted header backup could leave no backup at all.

## Upgrading

Update from **Settings**. On its first start the new version makes the boot partition read-only and installs `glovebox-boot-maintenance`. Kernel and system updates over SSH now have to run through it: see [Power loss and read-only boot maintenance](https://github.com/lubaxe/glovebox/blob/main/docs/power-loss.md).
